## แบบจำลองทางวิศวกรรม

ไบอัสแบบ voltage divider, NPN, โมเดลย่าน active: VBE เป็นค่าคงที่ที่รับเข้ามา
และ IC = beta × IB

**วิธีหลัก (ตำรา / Thevenin):**

```
VBB = VCC * R2 / (R1 + R2)
RB  = R1 * R2 / (R1 + R2)
IB  = (VBB - VBE) / (RB + (beta + 1) * RE)
IC  = beta * IB
IE  = (beta + 1) * IB
VB  = VBB - IB * RB
VC  = VCC - IC * RC
VE  = IE * RE
VCE = VC - VE
```

**วิธีอิสระ (nodal analysis แก้เป็นระบบเชิงเส้น 4×4):**

ตัวแปรไม่ทราบค่า `[VB, VC, VE, IB]` ใช้ KCL ที่แต่ละโหนดบวกเงื่อนไขแหล่งจ่าย VBE:

```
(VB - VCC)/R1 + VB/R2 + IB            = 0
(VC - VCC)/RC + beta * IB             = 0
VE/RE - (beta + 1) * IB               = 0
VB - VE - VBE                         = 0
```

แก้ด้วย Gaussian elimination + partial pivoting ที่เขียนเองใน `bjt.py`
วิธีนี้ไปถึงฟิสิกส์เดียวกันจากกฎของ Kirchhoff แทนที่จะใช้พีชคณิตจากตำรา
จึงเป็นการตรวจสอบที่เป็นอิสระจริง

**กติกาย่านการทำงาน:**

- Cutoff: `IB <= 0` → IC = IE = 0, VCE = VCC, เตือน
  "Cutoff: ไบอัสฐาน-อิมิตเตอร์ไม่ forward"
- Saturation: `IB > 0` และ `VCE <= VCE_SAT` (0.2 V) → แสดงค่าจากโมเดลเชิงเส้น
  ตามเดิม ไม่ clamp และเตือน "Saturation: VCE ที่คำนวณได้ต่ำกว่าหรือเท่ากับ
  VCE(sat) โมเดลย่าน active ใช้ไม่ได้แล้ว"
- Active: กรณีนอกเหนือจากข้างต้น

**กติกาการตรวจสอบข้ามวิธี:** เปรียบเทียบ IB, IC, VCE จากทั้งสองวิธี
ถือว่า "ตรงกัน" เมื่อผลต่างสัมพัทธ์มากที่สุด ≤ 1e-6 หน้าเว็บแสดงค่าทั้งสองชุด
และผลต่างสูงสุดเป็นเปอร์เซ็นต์

## กติกาการตรวจสอบอินพุต

| ฟิลด์ | กติกา | ตัวอย่างข้อความ |
|---|---|---|
| ทั้งหมด | ต้องแปลงเป็นจำนวนจำกัด (finite) ได้ | "VCC ต้องเป็นตัวเลข" |
| VCC | > 0 | "VCC ต้องมากกว่า 0 V" |
| R1, R2, RC, RE | > 0 | "R1 ต้องมากกว่า 0 โอห์ม" |
| beta | >= 1 | "beta ต้องมีค่าอย่างน้อย 1" |
| VBE | >= 0 และ < VCC | "VBE ต้องอยู่ระหว่าง 0 V กับ VCC" |

อินพุตไม่ถูกต้อง → render ฟอร์มเดิมพร้อมข้อความรายฟิลด์ และตอบ HTTP 400
อินพุตถูกต้อง → render หน้าเดิมพร้อมผลลัพธ์ (POST, ไม่ redirect, ไม่เก็บ state)
